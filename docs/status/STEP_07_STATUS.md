# Step 7 — Scheduled Recall and Authored Remediation

Confirmed course assessments seed version-pinned FSRS review cards with a first due time one day after confirmation. Due dates are stored as UTC and displayed in the learner's selected IANA timezone. The course directory offers genuine 3D review encounters and a deterministic Codex summary from stored checkpoint counts and approved text.

Review encounters select unused tutor-authored retry questions, excluding prompts already delivered in course attempts or reviews. An interrupted encounter resumes with the same server delivery ID. Help is recorded before the explanation is returned; assisted or incorrect answers receive the conservative FSRS Again rating. An independently correct due review receives Good. Early practice records evidence without rescheduling delayed recall. Duplicate submissions return the original result and cannot alter the schedule or add points. Exhausted banks explicitly request more authored coverage rather than recycling a revealed answer or generating content.

Tutor settings configure a 3–20 response window and minimum evidence of at least three. The default is five responses, three observations, and two errors/help events before remediation. Repeated difficulty returns existing explanations and resources, including prerequisite-level resources. Records retain the authored criterion/rubric; there is no unstable one-answer difficulty switch or generated lesson. Reviews do not modify course clearance, cosmetics, or team rewards.
